03完整的 AXI 定义

把 AXI 协议知识集中为单一事实来源，桥与 testbench 共同引用，杜绝字面量散落。

五通道 struct（全字段）

typedef struct packed {          // 写地址通道 AW
    logic [IDW-1:0]    awid;     // 写事务 ID（Lite 常为 0）
    logic [PW-1:0]     awaddr;   // 写地址
    logic [7:0]        awlen;    // 突发长度（Lite 恒 0）
    logic [2:0]        awsize;   // 突发大小
    logic [1:0]        awburst;  // 突发类型
    logic              awlock;   // 锁类型
    logic [3:0]        awcache;  // 缓存类型
    logic [PROT_W-1:0] awprot;   // 保护类型
    logic [3:0]        awqos;    // 服务质量（Lite 保留）
    logic [3:0]        awregion; // 区域标识（Lite 保留）
} aw_chan_t;

typedef struct packed { wdata, wstrb, wlast } w_chan_t;   // 写数据 W
typedef struct packed { bid, bresp }          b_chan_t;   // 写响应 B
typedef struct packed { arid, araddr, arlen, arsize, arburst, arlock,
                             arcache, arprot, arqos, arregion } ar_chan_t;  // 读地址 AR
typedef struct packed { rid, rdata, rresp, rlast } r_chan_t; // 读数据 R

协议常量

响应编码

RESP_OKAY=2'b00 · RESP_EXOKAY=2'b01 · RESP_SLVERR=2'b10 · RESP_DECERR=2'b11

突发 / 大小 / 锁 / 缓存 / 保护

04完整的 APB 定义

总线信号打包成 struct，阶段用枚举建模，时序规则形式化为可调用函数 —— 这就是「慢但要合法」的规格来源。

总线信号与阶段

typedef struct packed {        // APB 总线（PCLK/PRESETn 为全局）
    psel, penable, pwrite, paddr, pwdata,   // 主 → 从
    pready, prdata, pslverr                  // 从 → 主
} apb_bus_t;

typedef enum logic [1:0] {
    APB_IDLE  = 2'b00,   // 无传输
    APB_SETUP = 2'b01,   // 建立：PSEL=1, PENABLE=0，至少 1 拍
    APB_ACC   = 2'b10    // 访问：PSEL=1, PENABLE=1，等 PREADY（可插 wait）
} apb_phase_t;

时序规则 R1–R7（形式化）

规则内容实现位置
R1PENABLE 只能在 PSEL=1 时拉高penable_ok() · SVA
R2ACCESS 未完成（PREADY=0）不得中途退出phase_transition_ok() · SVA
R3SETUP 期间从机不得回 PREADYmonitor · SVA
R4传输在 PSEL && PENABLE && PREADY 完成transfer_done()
R5完成后 PENABLE/PSEL 归 0，下一传输重新 SETUP从机状态机 · SVA
R6写数据完成拍锁存；读数据完成拍后有效从机 always_ff
R7PSLVERR 只在完成拍有效从机 always_ff

05转换设计：AXI4-Lite → APB 桥

采用单状态机串行化：同一时刻只处理一个事务。对慢速 APB 外设天然友好 —— 桥在 ACCESS 态完整等待 PREADY，慢多少都合规。

状态机（11 态）

写路径 WRITE
S_IDLE→ S_AW_H / S_W_H / S_AWW_H→ S_WR_SETUP→ S_WR_ACC→ S_B_RESP→ S_IDLE
AW/W 可同拍接受（S_AWW_H）或分开发（S_AW_H 等 W，S_W_H 等 AW）； 握手态保持 READY 拉高，消除单拍可见的竞争。
▼
读路径 READ
S_IDLE→ S_AR_H→ S_RD_SETUP→ S_RD_ACC→ S_R_RESP→ S_IDLE
PRDATA 在 APB 完成拍锁存进 rdata_q，R 通道在 RVALID 时呈现 —— 数据绝不提前。

关键实现点

关注点做法
AXI 握手READY 只在对应状态拉高；握手态保持拉高避免单拍可见；VALID && READY 同拍完成
APB 时序SETUP 至少 1 拍（PSEL=1,PENABLE=0）→ ACCESS 等 PREADY → 完成后回 IDLE
慢速支持ACCESS 态直接等 apb.PREADY；从机插任意 wait states 桥都合规等待
错误回传PSLVERR 在完成拍置 slv_err → 响应通道输出 BRESP/RRESP=RESP_SLVERR，握手后清除
单驱动约束rdata_q/slv_err 各由独立 always_ff 驱动（避免 multiple-always-assigns）

06慢速外设：apb_slave_regs

寄存器堆

NREG=16 × 32-bit；地址 PADDR>>2 译码为字序号；复位清零

可配置 wait states

WAIT_CYCLES 参数：端口式版 3、SV 版 2（历史称 iverilog 版）；ACCESS 阶段逐拍递减，PREADY 拉低即等待

越界保护

idx >= NREG 时 PSLVERR=1，且不写存储器；桥转成 AXI SLVERR

阶段状态机

用 apb_phase_t 显式建模 APB_IDLE → APB_SETUP → APB_ACC，规则来自定义层

08向量化测试闭环（核心）

测试环节按 数据向量 → 激励向量 → 数据向量 三段显式组织， 并在第三段回写期望集，形成反向闭环。

① 数据向量集 DATA VECTOR
stim_vecs[$]，每条 = { write, same, addr, data, exp_resp, valid }
· 回环基本集：写 0..NREG-1 → 读 0..NREG-1（32 条）
· 随机向量：NTXN = 200 条（写 / 读 / 同发写混合）
· 边界向量：越界读写 2 条（exp_resp = SLVERR）
▼  逐向量驱动
② 激励向量驱动 STIMULUS
AxiDriver.run_vec(v, captured)
· 写：AW+W 同发（same=1）或分开发（AW 先 / W 后），握手判据 VALID&&READY
· 读：AR → 等 RVALID → 采 RDATA
· 捕获 captured.data（实际读回）与 captured.exp_resp（实际响应）
▼  期望 vs 实际
③ 数据向量比对 SCOREBOARD
· 写向量：resp==OKAY → ref_mem[addr] = data（更新期望向量集）
· 读向量：captured.data !== ref_mem[addr] → FAIL
· 越界：captured.resp !== SLVERR → FAIL
· 结束打印 ref_mem 快照，读写一致性可人工回溯
▲  反向闭环：③ 的 ref_mem 正是 ① 后续读向量的比对基准
闭环语义：写数据先进入期望向量集 → 读向量以它为基准比对 → DUT 往返（AXI → APB → 寄存器 → APB → AXI）的数据一致即判定通过。 任意环节出错都会在 ③ 以具体地址与数据对显式报错。
