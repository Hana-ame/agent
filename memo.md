Full backward-compat maintained: all state properties (completed, aborted, abort_reason, result, error, _script_module) proxy to the pipeline. 72/72 tests pass.
- **Step 2 (v2.0)**: Implemented Stateful Loops. Graph.validate() now collects back-edges via DFS and permits cycles only when back-edges carry `max_iterations > 0`. Vertex gains `loop_incoming_edges: Dict[str, int]`, `iteration_count: int`. Executor boots loop-destination vertices as sources, guards DONE assignment against concurrent loop re-entry, and dynamically re-schedules READY vertices on each scan. 11 new loop tests added. 83/83 tests pass.
- **Step 3 (v2.0)**: Implemented State Checkpointing and HITL. Added `SQLiteStateStore` for snapshot persistence (`framework/store.py`). Added `CheckpointedExecutor` to save snapshots after each vertex state change and support pause/resume. Added `HumanGateVertex` to support Human-in-the-Loop workflows. 27 new tests added for checkpointing and HITL. All 110 tests pass.
- **Refactor (PAUSED & Base Vertex Approval)**: Added `VertexState.PAUSED`. Integrated approval mechanism directly into base `Vertex` (`pause_for_approval()`, `approve(data)`, and JSON `settings: {"require_approval": true}`). `Vertex.receive_signal` intercepts `READY` -> `PAUSED` when approval is required. `Executor` and `CheckpointedExecutor` cleanly pause execution upon encountering `PAUSED` states, snapshotting the graph with `awaiting_approval`. 109/109 tests pass.
- **Features (Business Retry & Real-Time Event Streaming)**: Added business-logic / self-correction retry in `EdgePipeline` (`retry_policy` with `max_retries`, `backoff_factor`, `retry_on`, and `[SYSTEM FEEDBACK: ...]` prompt reflection). Added non-blocking real-time event streaming (`GraphEvent` and `async def stream()`) on `Executor` via sidecar `asyncio.Queue`. 5 new dedicated tests added in `tests/test_retry_and_stream.py`. All 114 tests pass.
