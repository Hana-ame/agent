# 探究报告：tiny CoT 加法模型到底学会了什么？

> 目标不是"做出能算加法的模型"，而是回答机制性问题：**它真的在计算，
> 还是在背模式？CoT 是推理还是查表？** 全部实验在 CPU 上完成，可复现。
> 主要对象：L4·D128 CoT 模型（`runs/20260830_044602`，bias0.5）。

## 总览：四个假说的证据链

| 假说 | 实验 | 结果 | 结论 |
|------|------|------|------|
| H1 CoT 功能必需性 | 篡改进位/和/操作数 | 和列 88.7% 敏感，操作数 0%，进位 ~10% | **模型读"和列"，不读操作数，几乎不读进位** |
| H1b 答案来源（决定性） | 答案 vs 各列和末位倒序 | **100% 吻合** | **模型 = "和末位读取器"** |
| H2 算法泛化 vs 记忆 | 训练 1-4 位，测 5-7 位 | **全部 0%** | **不泛化 → 长度受限的记忆模式** |
| H3 计算在哪层 | 逐层消融 | 末层 +2.742，其余 <0.01 | **读答案集中在最后一层** |
| H4 能力相变 | 细粒度训练量扫描 | 渐进单调，无陡峭拐点 | **无"突然开窍"，非相变** |

## H1：模型是"和末位读取器"，不是计算器

**方法**：给模型完整列（无答案）作前缀，令其生成答案；然后分别篡改三类 token，
看答案是否变化。**关键**：前缀不含答案，故任何变化都是真实的因果效应。

```
corruption      n   answer changed    rate
operand-perturb 150               0    0.0%   ← 改操作数,答案不变!
sum-perturb     150             133   88.7%   ← 改和列,答案大变
carry-flip      150              18   12.0%   ← 改进位,几乎不变
```

**对 0% 操作数敏感度的反证**（排除"模型不会算"的可能）：
裸前缀 `<BOS> a + b =`（无任何列）→ 模型正确率 **98.7%**。即模型**能**从操作数
生成正确列——它不是不会算，而是**在列已给定时只读列**。

**决定性验证**：模型的答案是否恰好 = 各列"和"的末位、倒序拼接？
（如 4517+6 的列和 13,2,5,4,0 → 末位 3,2,5,4,0 → 倒序 = 4523 ✓）

```
假说1 和末位倒序 == 真实答案:      200/200 = 100.0%
假说2 模型自写列的和末位倒序==模型答案: 200/200 = 100.0%
```

**解读**：模型的实际行为 = ① 从操作数生成正确的逐位列（含和）② 从每个和的
**末位**读出答案位并拼接。进位列（如 `13` 里的 1）**不参与**答案生成——
因为"和"本身已把进位编进数值里。CoT 竖式的"推理"表象下，模型做的是
**查表**：列是草稿纸，答案是从草稿纸抄的数字。

## H2：不泛化 → 记忆，不是算法

训练 max_digits=4（只见过 1-4 位操作数），测试更长：

```
4位 add: 35%  |  5/6/7位 add: 0% 0% 0%
4位 sub: 100% |  5/6/7位 sub: 0% 0% 0%
```

**结论**：若模型学会了通用竖式算法，5 位加法只是"多写两列"；但它**完全无法
处理 5 位**（0%）。这说明学到的是**长度受限的模式**：对 1-4 位的"列格式 + 读末位"
查表，而不是能外推到任意长度的进位算法。（4 位 add 35% 低于 sub 100% 是因为
4+4 会溢出到 5 位，超出已学的列数模式。）

## H3：读答案的计算集中在最后一层

逐层消融：移除某一层输出后，首位答案预测的损失增量：

```
layer 0: +0.002   layer 1: +0.002   layer 2: +0.006   layer 3: +2.742
```

前 3 层负责"生成列"（写草稿），**最后一层完成"和末位 → 答案"的读取/拼接**。
与 H1 的"草稿纸读取器"互为印证。

## H4：能力渐进爬升，非相变

L4·D128 细粒度扫描（600-2800 步）：

```
step  add1  add2  sub1  sub2
 600   20%    0%   20%    7%
1200   40%    7%   40%   20%
1600   67%   33%   87%   33%
2000  100%   67%  100%   60%
2400  100%  100%  100%   67%
2800  100%   87%  100%   93%
```

无陡峭"开窍"拐点，能力平滑上升——**在 tiny 规模上没有观察到"涌现=相变"**
的悬崖效应。（注：add3 在 2400 步 40%→2800 步 20% 是 15 次小样本噪声，趋势仍单调。）

## 综合结论

**这个模型没有学会算术，学会的是"写草稿 + 抄答案"。**
1. 它能从操作数写出正确的竖式列（这是真实学习，裸前缀 98.7%）
2. 但它从列的**和末位**读答案，进位不参与推理
3. 它只在训练见过的长度（≤4 位）内工作，绝不外推
4. "推理"的关键步骤被压进最后一层

**启示**：CoT/scratchpad 让小模型"显得"会推理，但机制上可能是**格式化的查表**
（列的和末位恰是答案）。这对评估语言模型推理能力有警示：准确率高 ≠ 有算法。
区分"真算法 vs 查表"的方法 = 长度外推测试（H2）+ 中间量篡改（H1）——两者
本报告都给了可复现方案。

## 局限

- 报告针对单模型（L4·D128 bias0.5）+ 单任务（≤4 位加减法）；H1 在另一个模型
  （无 bias 版）上复现过（0%/88.7%/6.7% 同构），H2/H3/H4 未跨模型复现。
- 注意力探针因近因效应有混淆，改用逐层消融作为因果证据。
- 4 位 add 溢出（结果 5 位）导致与 sub 的差异，是数据分布问题非机制问题。
